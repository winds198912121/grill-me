## 1. 業務概要

### 1.1 業務シナリオ

営業担当者が Salesforce の受注入力画面で受注情報を登録すると、そのデータが SAP S/4HANA にリアルタイム連携され、受注伝票が自動生成される。

```
[営業担当] → Salesforce受注入力 → SAP BTP (Middleware/マッピング) → SAP BAPI → 受注伝票登録 → [経理/物流]
```

## 3. エラー処理方針

| エラー種別 | 処理方針 |
|-----------|---------|
| **通信タイムアウト** | 最大3回リトライ（指数バックオフ: 1秒→2秒→4秒）。3回失敗時はエラーログ出力＋Salesforce画面にエラー表示 |
| **BAPI戻り値エラー（TYPE=E/A）** | RETURNテーブルのMESSAGEを取得し、Salesforce画面にエラーメッセージ表示。該当伝票はエラーキューに格納され、手動修正後再送 |
| **得意先コード不在** | SOLD_TOがSAPに存在しない場合、得意先マスタ未登録エラー。Salesforce側で得意先マスタ登録後に再送 |
| **品目コード不在** | MATERIALがSAPに存在しない場合、品目マスタ未登録エラー。品目マスタ登録後に再送 |
| **必須項目欠落** | バリデーションエラー。Salesforce画面で入力チェックを強化し、再送 |

**エラーログ出力先**: SLG1（SAP標準アプリケーションログ）
**エラーキュー管理**: Z-table `ZSD_ERR_QUEUE` に格納

## 5. 制約条件

- Salesforce側で受注番号を採番し、SAP側では外部採番を使用（SAPの内部採番は不使用）
- 得意先マスタ・品目マスタは事前にSAP側に登録済みであること
- 販売組織・流通チャネル・製品部門の組み合わせがSAP側で設定済みであること
- 本I/Fは受注伝票の「新規登録」のみを対象とし、変更・取消は別I/Fで対応
